# 🐑 羊の睡眠導入カウンターアプリ 仕様書

## アプリ概要

夜眠れない人のために、かわいい羊が夜の草原の柵を飛び越えながら自動でカウントしてくれる、
入眠サポートアプリです。日本語の「羊が一匹…」から始まり、徐々に英語の「One sheep…」へと
切り替わりながら、ウィスパー音声とBGMが時間経過で小さくなっていきます。

## 機能仕様

### 1. 羊アニメーション

| フェーズ | 使用画像 | 動作 |
|--------|---------|------|
| 歩行（助走） | `image_7d3023ad.png`（立ち絵） | 左端から柵に向かって歩く |
| ジャンプ | `image_8949a7a6.png`（ジャンプ） | 柵を飛び越える放物線アニメ |
| 着地・歩行 | `image_7d3023ad.png`（立ち絵） | 柵を越えて右端へ消え、また左端から出現 |
| 就寝演出 | `image_b4b4379f.png`（眠り） | 一定カウント後（例:100匹）に表示 |

- **背景**: `夜の草原と柵.png` を全画面背景として使用
- **柵**: 背景画像内の柵を飛び越えるタイミングでジャンプアニメを発火
- **速度**: 入眠に適した穏やかなリズム（約4〜6秒/回）
- **白背景処理**: 羊画像の白背景は `mix-blend-mode: multiply` で半透過表現（透過なしでも馴染む処理）

---

### 2. カウント表示とウィスパー音声

| カウント範囲 | 表示テキスト | 読み上げ |
|------------|------------|---------|
| 1〜10匹   | 「羊が　一匹…」〜「羊が　十匹…」 | 日本語カウント（ウィスパーTTS） |
| 11〜20匹  | 徐々に切り替わり（11: 羊が十一匹 → 15: 15 sheep…） | 日本語→英語混在 |
| 21匹〜    | 「21 sheep… 22 sheep…」 | 英語ウィスパー（Web Speech API） |

**ウィスパー音声の実装方法**
- **Web Speech API** を使用（`SpeechSynthesis`）
- `rate: 0.7`（ゆっくり）、`pitch: 0.8`（低め）、`volume: 0.6`（小さめ）で囁き風に設定
- 時間経過とともに `volume` を徐々に下げる（1時間で0.1程度まで）

---

### 3. BGM（睡眠導入音楽）

- **ファイル**: `ComfyUI_00096_(mp3cut.net).mp3`
- **音量調整バー**: スライダーUI（0〜100%）
- **ミュートボタン**: 🔊/🔇 トグル
- **フェードアウト**: 時間経過で自動的に音量を小さくしていく
  - 開始: 設定音量
  - 30分後: 設定音量の60%
  - 60分後: 設定音量の30%
  - 90分後: 設定音量の10%（ほぼ無音）
- **ループ再生**: ON

---

### 4. 時計機能（右上）

- **表示形式**: `HH:MM:SS`（リアルタイム更新）
- **デザイン**: 暗めの半透明パネル、月明かり風の温かみのあるフォント

---

### 5. 目覚ましタイマー機能

- **設定方法**: 時刻入力（`<input type="time">`）
- **アラーム音**: ニワトリの鳴き声（`cock-a-doodle-doo`）
  - Web Audio API で合成 **または** 音声ファイルを別途用意（確認事項参照）
- **起動時の挙動**:
  1. アラーム音が鳴る（3〜5回ループ）
  2. BGMとウィスパー音声がフェードアウト
  3. 「おはようございます！」のメッセージ表示
  4. 眠っている羊が起き上がる（眠り画像→立ち絵へ）
- **キャンセル**: 「アラームをキャンセル」ボタン

---

### 6. 就寝ムード演出

- **星のキラキラエフェクト**: 背景に星がゆっくり瞬く（CSS animation）
- **徐々に暗くなるオーバーレイ**: 時間経過で画面全体が少しずつ暗くなる
- **おやすみ表示**: 一定カウント（例: 50匹）を超えると「おやすみなさい…」のテキストがフェードイン

## 確認事項（エクスさんへ）

> [!IMPORTANT]
> 以下の点についてご確認・ご回答をお願いします。

### ❓ Q1. 画像ファイルの保存場所
ご用意いただいた画像・BGMファイルはどのフォルダに保存されていますか？
アプリのHTMLファイルと同じフォルダに置くと読み込みやすいですが、
現在のパスを教えていただければそのまま指定できます。

### ❓ Q2. 羊画像の白背景について
羊の画像は白背景とのことです。
- **案A**: `mix-blend-mode: multiply` を使って背景に馴染ませる（簡単・コストなし）
- **案B**: AI透過処理（別ツールで透過PNG化）してから使う（より綺麗）

どちらがご希望ですか？まずは案Aで試してみて、気になれば案Bに切り替えることも可能です。

### ❓ Q3. ニワトリのアラーム音
ニワトリの鳴き声ファイルはお持ちですか？
- **お持ちの場合**: ファイルパスを教えてください
- **お持ちでない場合**: Web Audio APIで合成音を生成します（実際のニワトリ音には劣りますが動作します）

### ❓ Q4. カウントの切り替えタイミング
「途中からシープに切り替える」について、どの数から切り替えますか？
- 案: 10匹を超えたあたり（11匹目）から徐々に英語へ
- 案: ちょうど10匹で一区切りつけてから切り替え

### ❓ Q5. アプリの設置場所
HTMLファイルはどのフォルダに作成しますか？
現在 `g:\workspaces` をワークスペースとして使っているようですが、
`g:\workspaces\sheep-sleep-counter\` に作成してよいでしょうか？

### ❓ Q6. ウィスパー音声の言語環境
Web Speech APIはブラウザの言語設定を使います。
日本語の読み上げ（「羊が一匹」）が正しく発音されるか、
まず簡易版を試作して確認するのが良さそうです。
（もし日本語音声が不安定な場合、ひらがな表記で工夫します）
